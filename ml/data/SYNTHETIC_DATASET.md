# Synthetic Stress-Risk Dataset — v1

**THIS IS SYNTHETIC DEMO DATA. IT IS NOT REAL CAPF PERSONNEL DATA.**

There is no real CAPF personnel dataset available for this prototype. This
file was generated by `ml/data/generate_synthetic.py` with a fixed random
seed (`42`) so it is fully reproducible:

    python -m ml.data.generate_synthetic
    python -m ml.data.validate_synthetic

## Provenance

- Generator: `ml/data/generate_synthetic.py`
- Seed: `42` (fixed; same seed -> identical file)
- Size: 4,800 rows = 1,200 synthetic personnel x 4 weekly snapshots
- Timeline anchor: weekly snapshots through 2026-09-07 (synthetic)
- Personnel keys are opaque and clearly synthetic (`SYN-` prefix). No real
  names, phone numbers, addresses, personnel IDs, or unit identities.

## Columns

| column | meaning | range |
|---|---|---|
| `personnel_key` | opaque synthetic id | `SYN-*` |
| `week_start` | snapshot Monday (ISO) | 2026 dates |
| `duty_hours_7d` | weekly duty hours | 0-84 |
| `rest_hours_7d` | avg daily rest | 0-14 |
| `sleep_hours_7d` | avg daily sleep | 0-12 |
| `workload_level` | self-rated workload | 1-10 |
| `deployment_days_30d` | days deployed in last 30 | 0-30 |
| `leave_gap_days` | days since last leave | 0-365 |
| `leave_count_180d` | leave episodes in 180 d | 0-10 |
| `transfers_12m` | transfers in 12 months | 0-6 |
| `duty_intensity` | composite recent-duty intensity | 0-100 |
| `self_report_stress` | self-reported stress | 1-10 |
| `risk_label` | SYNTHETIC target class | LOW / MEDIUM / HIGH |

## Label method (documented, not clinical)

`risk_label` is produced by a weighted multi-factor heuristic plus noise —

    risk_score = 0.22 * duty_z + 0.22 * rest_z + 0.16 * workload_z
               + 0.10 * deployment_z + 0.12 * stress_z + 0.12 * latent_stress
               + 0.06 * intensity_z + 0.05 * leave_gap_z + 0.05 * transfers_z
               + N(0, 0.5)

then thresholds at the 42nd and 75th percentiles give roughly
LOW 42% / MEDIUM 33% / HIGH 25%. No single feature is a trivial cutoff; a
per-person latent term and per-row noise keep the task learnable but not
memorizable.

**These labels are a stand-in for demonstration and pipeline development.
They must never be presented as clinically validated stress diagnoses.**
